# CaspianHC

website for Caspian Hack Club. built to display our hardware projects, custom pcbs, microcontrollers, and the crew.

## current features

- dark / monospace UI with custom css
- interactive project toggle (individual vs club builds)
- member list with social links (github, discord, instagram)
- fully responsive layout

## tech stack

- html5
- css3 (flexbox, grid)
- vanilla javascript
- font awesome

## future updates

- photo gallery for hardware builds
- club join / contact section
- project updates & devlogs
